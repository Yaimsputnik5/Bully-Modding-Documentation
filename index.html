What is this?

Just a place to store some data you'll inevitably need when modding the game.
Note that some stuff might be incomplete.

The original idea was to create a blog like Dreamcastify, but for BULLY.
It's not a thing yet, but I might make it in the future.

BULLY documentation is a bit messy, and is split across a few places (see Extra Resources on the top right).
My site only exists to quickly add info not present in others or for personal convenience, but you're free to take the information and add it elsewhere, just have common sense and give credit when directly taking info, as you would normally do.
